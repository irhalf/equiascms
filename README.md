Project Title: Equias Farm Agri-Tourism Booking & Product Catalog - Strapi CMS

Student Name: Jhon Rhalf N Pascual

Course and Section: BSIT 3-F3

Project Description: A digital platform designed to promote farm tourism and showcase local agricultural goods. It enables visitors to schedule and book farm tours, activities, and workshops while providing an interactive catalog to browse and order fresh produce, farm-to-table specialties, and artisanal farm products directly from Equias Farm.

Technologies Used: Next.js, TypeScript
